# Pyzerion — AI-Powered Digital Transformation & Development

Architecting the future of corporate software. Pyzerion builds ultra-premium, dark-themed digital experiences, AI-driven voice assistants, specialized administrative CRM dashboards, and robust enterprise platforms.

## Tech Stack
- **Frontend Framework**: React 18 with TypeScript & Vite
- **Styling**: Tailwind CSS & Vanilla CSS (Obsidian dark theme, glassmorphism, elegant gold accents)
- **Database / Backend**: Supabase (leads tracking, automatic fallbacks, service role integration)
- **Routing**: React Router DOM v6
- **Animations & Interaction**: Custom CSS keyframes, glow pulses, smooth-scroll, and interactive hover scales

## Core Features
1. **Interactive Watch Showcases**: High-end watch silhouette presentation with champagne gold accents (`#C5A572`) and bespoke custom dial customizers.
2. **Central CRM Panels**: Dedicated, responsive back-end mockup systems built specifically for dynamic inventory synchronization, price scale management, and 1-click publishing.
3. **Advanced Contact Integrations**: Lead capture form posting directly to Supabase databases with robust table fallbacks, custom webkit autofill styling overrides, and real-time toast alerts.
4. **Live CTAs**: Integrated aircraft engine expert showcases, aviation charter platforms, cargo logistics, and Retell AI voice assistants with direct live platform links.
